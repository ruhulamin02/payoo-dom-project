# 💰 Payoo DOM Banking App

A simple DOM-based banking simulation project built with **HTML**, **Tailwind CSS**, and **Vanilla JavaScript**.  
Users can add money, cash out, and view a real-time transaction history — all without any backend.

---

## 🚀 Features

- 💵 **Add Money** — Select bank, enter amount, and securely add balance.
- 💸 **Cash Out** — Withdraw money using agent number and 4-digit PIN validation.
- 📊 **Dynamic Transaction History** — Shows all add/cash-out actions instantly.
- 🔐 **PIN Protection** — Basic security (default PIN: `1234`).
- 🎨 **Responsive UI** — Clean TailwindCSS design inspired by modern mobile banking apps.
- ⚙️ **DOM Manipulation Practice** — All actions handled through JavaScript DOM methods.

---

## 🧠 Learning Goals

This project demonstrates:
- Working with the **DOM API**
- Handling **user input & validation**
- **Updating the UI dynamically** using JavaScript
- Using **utility functions** for clean and reusable code
- Managing multiple sections with **toggle visibility**
