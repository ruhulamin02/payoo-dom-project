# Payooo DOM Project

A digital wallet UI and functionality project built using **HTML**, **Tailwind CSS**, **DaisyUI**, and **JavaScript (DOM manipulation)**.

## Features
- Login using mobile number and 4-digit PIN  
- Dynamic balance update using DOM  
- Interactive buttons: Add Money, Cashout, Transfer, etc.  
- Responsive mobile-first layout  

## Tech Stack
- HTML5  
- Tailwind CSS  
- DaisyUI  
- JavaScript (DOM)
